# Data formats and how to add a source

This page describes every data artefact in the repository: the **catalogue**, the **downloaded CSV + provenance sidecar**, the **open snapshot** in `data/`, the **data section of a spec**, and a step-by-step recipe to **add a new source** with a worked example. Field names in JSON are Spanish (`fuente`, `unidad`, `frecuencia`…) because the engine's contract is Spanish; they are glossed here.

The one rule behind everything: **exactness**. Every figure on screen must trace to a row of a CSV, which traces to a URL, a licence and a SHA-256. Nothing is interpolated, rounded or filled in.

## 1. The catalogue — `catalogo/series.json`

A JSON array. Each element describes one downloadable series (nothing is downloaded until asked).

```jsonc
{
  "id": "fred_unrate",                       // stable id, [a-z0-9_]; also the file name datos/biblioteca/<id>.csv. Never reused for a different series.
  "nombre": "Tasa de desempleo EE. UU.",     // display name (Spanish)
  "categoria": "Empleo",                     // grouping in the studio
  "etiquetas": ["fred", "unrate", "ee. uu."],// search keywords
  "adaptador": "fred",                       // which adapter in servidor/catalogo.mjs (or servidor/fuentes_extra.mjs) downloads it
  "args": {"id": "UNRATE"},                  // adapter arguments (adapter-specific, see below)
  "unidad": "%",                             // unit shown to the user
  "frecuencia": "Mensual",                   // frequency: Diaria | Semanal | Mensual | Trimestral | Anual …
  "fuente_original": "FRED (Federal Reserve Bank of St. Louis)",   // source name for on-screen credit
  "fuente_corto": "FRED · UNRATE",           // short credit line
  "licencia": "Dominio público (obra del gobierno de EE. UU.: U.S. Bureau of Labor Statistics), redistribuida por FRED; citar la fuente",
  "nota": "…",                               // caveats shown in the studio
  "titulo_fuente": "…",                      // (optional) official title of the series
  "pais": {"iso3": "COL", "nombre": "Colombia", "region": "…"},   // (country series only)
  "tema": "Economía",                        // (country series only) theme
  "ampliacion": "2026-11-04"                 // (series added by scripts/construir-ampliacion.mjs) marks entries that script owns and may regenerate
}
```

Required for every new entry (enforced by `scripts/prueba-datos-nuevos.mjs`): `id`, `nombre`, `categoria`, `adaptador`, `args`, `unidad`, `frecuencia`, `fuente_original`, `licencia`.

**Where the entries come from** (all are code, none is hand-edited in the JSON):

| Entries | Generated by |
|---|---|
| Pink Sheet commodities, FRED, Yahoo, Coin Metrics, Shiller, OWID, Poland, a few WB/IMF/Eurostat/Treasury/TRM series | `scripts/construir-catalogo.mjs` (curated lists) |
| Country series `pais_<ISO3>_<indicator>` | `servidor/paises.mjs` → `scripts/construir-paises.mjs` (also writes `catalogo/paises.json` with what the source does *not* publish) |
| Expansion (FRED sectors/CPI/housing/rates/FX, OWID energy & climate, Eurostat, Treasury, NASA/NOAA/USGS, datos.gov.co, World Bank aggregates) | `servidor/ampliacion.mjs` → `scripts/construir-ampliacion.mjs` (idempotent; never touches existing entries) |

## 2. Adapters

An adapter is an async function `({...args}) → {columnas, filas, url, urlDatos, unidad?, notaFuente?}` registered in `ADAPTADORES` (`servidor/catalogo.mjs`; newer ones live in `servidor/fuentes_extra.mjs` and are installed from there).

- `columnas`: `['fecha', '<value column name>']`.
- `filas`: `[['YYYY-MM-DD', value], …]`, strictly increasing dates. **Annual series use `YYYY-01-01`**; monthly `YYYY-MM-01`; quarterly the first day of the quarter. BCE years are negative integers (`-10000-01-01`); AD years below 1000 are not zero-padded (`1-01-01`) — the ingester accepts `-?\d{1,6}`.
- `url`: human page of the series; `urlDatos`: the exact request that returned the data. Both must start with `http`.
- `notaFuente`: what was left out and why (omitted gaps, excluded projections, interpolated months dropped…). This text travels to the compile report.
- **Never** interpolate, forward-fill, rescale or round. Values are kept as the exact strings the source returns.

| Adapter | Source | `args` | Notes |
|---|---|---|---|
| `fred` | FRED `fredgraph.csv` | `{id}` | full history; `.` (missing) rows are dropped by `descargar()` |
| `worldbank` | World Bank WDI API v2 | `{indicador, pais}` | `pais` is ISO3 or an aggregate (`WLD`, `LCN`…); null years omitted |
| `bancomundial` | World Bank Pink Sheet (xlsx) | `{columna}` | xlsx URL is discovered on the commodity page |
| `imf` | IMF DataMapper | `{indicador, pais, proyecciones?}` | restricted licence; projections excluded by default |
| `eurostat` | Eurostat JSON-stat 2.0 | `{dataset, filtros}` | every dimension except `time` must be fixed by `filtros` |
| `owid` | Our World in Data CSV | `{slug, entidad, columna?}` | `entidad` e.g. `"World"` |
| `tesoro` | Treasury FiscalData, Debt to the Penny | `{campo}` | |
| `fiscaldata` | Treasury FiscalData, any endpoint | `{endpoint, campo, filtro?, campoFecha?}` | `campoFecha` defaults to `record_date` |
| `nasa_giss` | NASA GISTEMP v4 | `{region}` (`GLB`/`NH`/`SH`) | wide year×month table → monthly |
| `noaa_gml` | NOAA GML CSV | `{archivo, columna}` | months flagged as interpolated by NOAA are dropped |
| `noaa_oni` | NOAA CPC Oceanic Niño Index | `{}` | dated at the centre month of each 3-month season |
| `usgs_sismos` | USGS ComCat count service | `{minmag, desde}` | complete calendar years only |
| `socrata_suma` | datos.gov.co (Socrata), monthly sum | `{dataset, anio, mes, valor}` | text field with thousands commas; summed in integer cents |
| `trm`, `nbp`, `gus`, `yahoo`, `coinmetrics`, `shiller`, `archivo` | see [DATA_SOURCES.md](DATA_SOURCES.md) | | |

## 3. Downloaded series — `datos/biblioteca/<id>.csv` (git-ignored)

```csv
fecha,UNRATE
1948-01-01,3.4
1948-02-01,3.8
```

- Header: first column `fecha`; the second column's name is **source-specific** (`UNRATE`, `NY.GDP.MKTP.CD_COL`, `WALCL`…).
- UTF-8, `\n` line endings, comma separated, no quoting (values never contain commas), no blank values.
- Next to it, `<id>.csv.meta.json` is the **provenance sidecar** (written by `descargar()` in `servidor/catalogo.mjs`):

```jsonc
{
  "id": "fred_unrate",
  "sha256": "7619…3005",                   // SHA-256 of the CSV file; the compiler warns if the file changes afterwards
  "descargado": "2026-11-04",              // download date
  "fuente": {
    "corto": "FRED · UNRATE", "nombre": "FRED (Federal Reserve Bank of St. Louis)",
    "url": "https://fred.stlouisfed.org/series/UNRATE",                       // page
    "urlDatos": "https://fred.stlouisfed.org/graph/fredgraph.csv?id=UNRATE",  // the exact request
    "obtenido": "2026-11-04", "licencia": "…", "unidad": "%", "frecuencia": "Mensual", "notaFuente": null
  },
  "filas": 944, "inicio": "1948-01-01", "fin": "2026-09-01",                  // MEASURED at download, never assumed from the catalogue
  "nota": "…"
}
```

`catalogo/verificado.json` (git-ignored) keeps `{inicio, fin, filas, descargado, sha256, url}` per downloaded id, plus the verification records (`_verificacion_paises`, `_verificacion_datos_nuevos`).

## 4. The open snapshot — `data/` (in git)

`data/<id>.csv` is a **byte-for-byte copy** of the downloaded CSV (same format as above) for series whose licence allows redistribution; `data/MANIFEST.json` carries provenance:

```jsonc
{
  "generated": "2026-11-04", "files_count": 2500, "total_bytes": 12345678,
  "trimming": "none — …", "excluded_for_license": [{"id": "…", "motivo": "…"}],
  "files": [{
    "id": "fred_unrate", "file": "fred_unrate.csv", "name": "…", "category": "…",
    "source": "…", "source_url": "…", "data_url": "…",
    "license": "Public domain (work of the U.S. government: …)", "license_class": "public-domain",   // or "CC-BY-4.0"
    "attribution": "Source: …", "frequency": "Mensual", "unit": "%",
    "downloaded": "2026-11-04", "sha256": "…", "rows": 944, "first": "1948-01-01", "last": "2026-09-01",
    "trimmed": false, "bytes": 12345,
    "provenance": { /* the full .meta.json above */ }
  }]
}
```

**Runtime fallback.** `servidor/datos.mjs` exposes `rutaBiblioteca(id)`, `hayEnBiblioteca(id)`, `metaSerie(path)` and `rutaInstantanea(path)`: if `datos/biblioteca/<id>.csv` does not exist but `data/<id>.csv` does, the snapshot file is read and its provenance comes from `MANIFEST.json` (`provenance`). The fallback only applies to files inside `datos/biblioteca/` or `data/`; a user's own file that happens to share an id never inherits a snapshot provenance. `sec/<TICKER>_serie.csv` (quarterly company series) has no fallback path — it is a plain data file.

Regenerate with `node scripts/actualizar-instantanea.mjs` (`--refrescar` re-downloads). See [data/README.md](../data/README.md).

## 5. The data section of a spec

A spec is a JSON file in `specs/`. Its `datos` object maps a local name to a file and a source (full reference: [SPEC_REFERENCE.md](SPEC_REFERENCE.md)):

```jsonc
"datos": {
  "d": {
    "archivo": "datos/biblioteca/fred_unrate.csv",   // or data/fred_unrate.csv, or your own file in entradas/
    "x": "fecha", "tipoX": "fecha",
    "columnas": [{"col": "UNRATE", "nombre": "Unemployment", "color": "teal", "unidad": "%"}]
  }
}
```

The compiler (`servidor/compilar.mjs`) refuses a dataset with no source: for library series it finds the source in the `.meta.json` (or `MANIFEST.json`), for your own files you must declare `"fuente": {"nombre", "url", "obtenido", "licencia"}`. It warns on non-commercial or personal-use licences and on a changed SHA-256.

## 6. How to add a new source — step by step

**Goal:** add a monthly series from a fictional open API `https://api.example.org/v1/series/{code}.csv` (columns `date,value`).

1. **Check the licence first.** Open the provider's terms. Record the exact licence text and whether commercial reuse and redistribution are allowed. If unclear, *do not* put it in `data/`, and mark the catalogue licence as restricted.
2. **Find the real endpoint with `curl`** and read what the API actually returns (gaps, flags, text-encoded numbers, interpolated values, paging, rate limits). Write the gotchas down.
3. **Write the adapter** in `servidor/fuentes_extra.mjs` inside `instalar(ADAPTADORES, pedir)`:

```js
ADAPTADORES.example = async function example({code}) {
  const urlDatos = `https://api.example.org/v1/series/${encodeURIComponent(code)}.csv`;
  const L = (await pedir(urlDatos)).trim().split(/\r?\n/);
  if (L[0] !== 'date,value') throw new Error(`example ${code}: unexpected header «${L[0]}»`);
  const filas = L.slice(1).map((l) => l.split(',')).filter((c) => c[1] !== '' && Number.isFinite(Number(c[1])))   // gaps are dropped, never filled
    .map((c) => [`${c[0].slice(0, 7)}-01`, c[1]]);                                                              // keep the exact string
  if (!filas.length) throw new Error(`example ${code}: no values`);
  return {columnas: ['fecha', code], filas, url: `https://example.org/series/${code}`, urlDatos, unidad: 'index (2015=100)',
    notaFuente: 'Example Institute · gaps omitted · provisional values in the last 3 months'};
};
```

4. **Add the entries** to `servidor/ampliacion.mjs` (one object per series, all required fields, honest `licencia`, caveats in `nota`) and run `node scripts/construir-ampliacion.mjs`. The id must be new and stable (`example_<code>`); existing ids are never overwritten.
5. **Download every new series** — `node scripts/bajar-ampliacion.mjs --solo=example_` — and fix or drop any id that fails.
6. **Write the verification** in `scripts/prueba-datos-nuevos.mjs`: compare first and last values (and a sample in the middle) against the official source through an **independent request** (different endpoint, parameter or format), or cross-check against a second publisher or an accounting identity. Add the contrast with `contraste(...)`; run `node scripts/prueba-datos-nuevos.mjs --doc`, which rewrites [data-verification.md](data-verification.md).
7. **Decide on the snapshot.** If the licence allows redistribution, add the family to `scripts/actualizar-instantanea.mjs` (with its licence text and attribution) and run it; otherwise add it to the exclusions list so the manifest says why it is absent.
8. **Document** it in [DATA_SOURCES.md](DATA_SOURCES.md) (what it brings, endpoint, licence, limits, cadence, gotchas, how it was verified).
9. Run the tests: `node scripts/prueba-conectores.mjs`, `node scripts/prueba-paises.mjs`, `node scripts/prueba-datos-nuevos.mjs`.

Rules of thumb: omit rather than interpolate; keep the source's own strings; declare every transformation in `notaFuente`; never silently change an existing series (a fix that changes values gets a new id or a note); if the source blocks scripts, say so instead of working around it.
