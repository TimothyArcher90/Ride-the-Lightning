## E. Hallazgos que cambian decisiones previas

1. **FRED**: el repo usa `fredgraph.csv` sin clave. La API oficial pide clave y un aviso obligatorio; las series con «Copyright» en las notas dependen de terceros. Pendiente decidir (C6/D6).
2. **Banco Mundial**: «CC BY 4.0 por defecto» no es «todo CC BY»; hay datasets con ODbL o licencias propias. Con 3.911 series hace falta una auditoría por `source id` (C4).
3. **OWID Grapher**: confirmado que NO es reutilizable (README). Un resultado de búsqueda decía que seguía en MIT; manda el README que se abrió directamente. Sus DATOS (CSV/API) sí están en CC BY 4.0 (C5).
4. **FMI**: sigue siendo el único dato con permiso pendiente para uso comercial (C7).
